## <a id="style-css">CSSによるドキュメントのレイアウト</a>

HTMLとXMLをCSSによってスタイル付けすることができます。

[CSS Level 2 Revision 1](https://www.w3.org/TR/CSS21/) を基礎にしつつ、
CSS Paged Media、Writing Modes、Multi-column Layout、Grid Layout、論理プロパティ、
Selectors Level 4など、CSS 3以降の各モジュールを実装しています。
したがって、製品全体を「CSS 2.1準拠」とだけ表すのは適切ではありません。
実装範囲と既知の制限は**機能一覧**(サーバー製品の説明書)および[資料集](#appx-css)を参照してください。

### スタイルシートの型

特に型が指定されていないスタイルシートはCSS(MIME型text/css)として認識します。
Content-Style-Typeヘッダ (HTML中では `<meta http-equiv="Content-Style-Type" content="...` といった記述) やstyle要素のtype属性等によってtext/css以外がスタイルシートの型として指定されている場合は、
スタイルシートをCSSとして認識しません。

### <a id="style-css-mediatypes">メディアタイプ</a>

style要素のmedia属性、あるいはCSSの@media指示子等でスタイルシートが適用されるメディアタイプが限定されている場合、
通常は印刷メディア向けのスタイルだけを適用します。 すなわち、メディアタイプはall print
paged visual bitmap staticのいずれかです。

なお、ユーザーエージェントのメディアタイプは <span class="ioprop">output.media_types</span>
入出力プロパティによって変更することができます。 適用するCSSの[メディアタイプ名またはメディアグループ名](https://www.w3.org/TR/CSS2/media.html)を列挙してください。
例えば、ブラウザの画面表示用のスタイルを適用する場合は"all visual bitmap static screen
continuous"を設定してください。

### ドキュメント中にスタイルシートを記述する

ドキュメント中にスタイルおよびスタイルシートを記述する方法は以下の3通りがあります。

1. HTMLのstyle属性
1. HTMLのstyle要素
1. jp.cssj.stylesheet処理命令

#### HTMLのstyle属性

style属性により、各要素に直接スタイルを指定する方法です。
style属性には、適用したいCSSのプロパティを記述してください。

```html
<html>
<body style="border: 1px Black dashed;">
<h1 style="font-style: italic;">題名</h1>
<p style="text-decoration: underline;">本文<span style="font-size: x-large;">大きなテキスト</span>本文</p>
</body>
</html>
```

上記の例は以下のように表示されます。

<div title="style属性によるスタイルの指定(表示結果)" class="example">
	<div style="border: 1px Black dashed;">
		<div style="font-size: xx-large; font-style: italic;">題名</div>
		<div style="text-decoration: underline;">
			本文<span style="font-size: x-large;">大きなテキスト</span>本文
		</div>
	</div>
</div>

style要素はHTMLだけではなく、XML文書内でも利用可能です。
ただし、style要素が名前空間"http://www.w3.org/1999/xhtml"に属するように、名前空間宣言を行ってください。

```xml
<?xml version="1.0">
<body xmlns:html="http://www.w3.org/1999/xhtml" html:style="border: 1px Black dashed;">
<h1 html:style="font-style: italic;">題名</h1>
<p html:style="text-decoration: underline;">本文<span html:style="font-size: x-large;">大きなテキスト</span>本文</p>
</body>
```

#### HTMLのstyle要素

一般的なブラウザと同じくstyle要素内にスタイルシートを記述することができます。

```html
<html>
<head>
<style type="text/css" media="print">
	body {
		border: 1px Black dashed;
	}
	h1 {
		font-style: italic;
	}
	p {
		text-decoration: underline;
	}
	span {
		font-size: x-large;
	}
</style>
</head>
<body>
<h1>題名</h1>
<p>本文<span>大きなテキスト</span>本文</p>
</body>
</html>
```

style要素はなるべくhead要素内に記述してください。 他の場所のstyle要素も認識しますが、
ドキュメント中でstyle要素が現れる以前の部分には、記述されたスタイルが適用されなくなります。

また、XMLドキュメント中ではstyle要素によるスタイル指定は行わず、
次に説明するjp.cssj.stylesheet処理命令を使用するか、
あるいは一般的なブラウザでもサポートされているxml-stylesheet処理命令を使用してください。

#### jp.cssj.stylesheet処理命令

jp.cssj.stylesheet処理命令はHTMLのstyle要素に相当する機能を処理命令
(`<?`で始まり`?>`で終わるHTMLやXML中の特別な記述。) によって実現したものです。 HTML,
XMLの両方のドキュメントの先頭で使用することができます。

style要素のtype, media属性に相当する部分はHTMLの属性と同様の形式で記述し、
スタイルシートは'[]'で囲みます。

```
<?jp.cssj.stylesheet type="text/css" media="print" [
	body {
		border: 1px Black dashed;
	}
	h1 {
		font-style: italic;
	}
	p {
		text-decoration: underline;
	}
	span {
		font-size: x-large;
	}
] ?>
<html>
<body>
<h1>題名</h1>
<p>本文<span>大きなテキスト</span>本文</p>
</body>
</html>
```

### 外部のCSSの使用

ドキュメントと外部のスタイルシートを結びつける方法は以下の3通りがあります。

1. HTMLのlink要素
1. CSSの@import指示子
1. xml-stylesheet処理命令

#### HTMLのlink要素

一般的なブラウザと同様に、link要素によってスタイルシートをドキュメントに関連付けることができます。

```
<link rel="stylesheet" type="text/css" media="print" href="スタイルシートのURL">
```

rel属性にキーワードalternateを加えることで、
1つのドキュメントに対して、複数の代替スタイルシートを用意することができます。 title属性は代替スタイルシートの名前です。

```
<link rel="alternate stylesheet" title="a" type="text/css" media="print" href="a.css">
<link rel="alternate stylesheet" title="b" type="text/css" media="print" href="b.css">
```

代替スタイルシートは通常は適用されませんが、 <span class="ioprop">input.stylesheet.titles</span>
に代替スタイルシートのtitleを設定することで、適用するスタイルシートを選択することができます。

#### CSSの@import指示子

これは、HTMLのstyle要素とCSSの@importを組み合わせる方法です。

```html
<style type="text/css" media="print">
	@import url(スタイルシートのURL);
</style>
```

HTMLのstyle要素の代わりに、jp.cssj.stylesheet処理命令を使うこともできます。

```
<?jp.cssj.stylesheet type="text/css" media="print" [
	@import url(スタイルシートのURL);
] ?>
```

#### <a id="style-xml-stylesheet">xml-stylesheet処理命令</a>

[xml-stylesheet処理命令を使う方法](https://www.w3.org/TR/xml-stylesheet/)は、
一般的なブラウザでXMLとスタイルシートを結びつけるために広くサポートされている方法です。

スタイルシートを適用したいドキュメントの冒頭で、以下のように記述してください。

```
<?xml-stylesheet type="text/css" media="print" href="スタイルシートのURL"?>
```

alternate属性はlink要素のrel属性に対するalternateの指定に相当するものです。
xml-stylesheet処理命令でalternate="yes"を指定することは、link要素にrel="alternate
stylesheet"を設定するのと同じ意味です。

```
<?xml-stylesheet alternate="yes" title="a" type="text/css" media="print" href="a.css"?>
<?xml-stylesheet alternate="yes" title="b" type="text/css" media="print" href="b.css"?>
```

<p id="style-xml-stylesheet-xslt">

xml-stylesheetのtype属性にはCSSだけでなくXSLTスタイルシートを指定することもできます。
この場合、type属性にtext/xslを設定し、href属性にはXSLTファイルの指定してください。

</p>

### <a id="style-css-selectors">使用できるセレクタ<span class="since">4.0.0</span></a>

次のセレクタを使用できます。

| 種類 | 記法 |
| --- | --- |
| 要素型・全称 | `E` `*` |
| クラス・ID | `.c` `#i` |
| 属性 | `[a]` `[a=v]` `[a~=v]` `[a|=v]` `[a^=v]` `[a$=v]` `[a*=v]` |
| 結合子 | 子孫(空白) 子`>` 隣接兄弟`+` 一般兄弟`~` |
| 構造擬似クラス | `:root` `:first-child` `:last-child` `:only-child` `:empty` `:first-of-type` `:last-of-type` `:only-of-type` `:nth-child()` `:nth-last-child()` `:nth-of-type()` `:nth-last-of-type()` |
| 論理擬似クラス | `:not()` `:is()` `:where()` `:has()` |
| その他の擬似クラス | `:link` `:lang()` `:dir()` `:scope` |
| 擬似要素 | `::before` `::after` `::first-line` `::first-letter` `::marker` `::footnote-call` `::footnote-marker` |
| @page擬似クラス | `:first` `:left` `:right` |

属性セレクタの値の比較とIDの比較は、大文字小文字を区別しません(HTMLとの互換のため)。
擬似要素はコロン1つの記法(`:before`など)でも書けます。
`:nth-child()`系は`odd`、`even`、`An+B`の記法に対応しています。

<div class="note">

**次の擬似クラスは、<span class="ioprop">processing.pass-count</span>に
2以上を設定しないと一致しません**(警告は出ず、単に一致しなくなります)。

`:last-child` `:only-child` `:last-of-type` `:only-of-type` `:empty`
`:nth-last-child()` `:nth-last-of-type()` `:has()`

いずれも「後ろに何が来るか」が分からないと判定できないため、
文書を1回読むだけでは決まりません。
<a href="#style-multipass-required" class="pageref">2パスが必要な機能</a>を参照してください。

</div>

次のものには対応していません。

- `:hover` `:focus` `:active` 等の動的擬似クラス。静的な組版には概念がありません
- `::selection`。選択状態を持たないため、構文は通りますが一致しません
- `:has()`の入れ子(`:has(:has(...))`)
- `:nth-child(An+B of S)`(Selectors 4 の of 構文)
- `@scope`

未知のセレクタは、エラーにせず「一致しないもの」として処理を続けます。

### <a id="style-css-nesting">規則の入れ子<span class="since">4.0.0</span></a>

規則の中に規則を書けます。内側のセレクタは外側のセレクタと組み合わされます。

```css
.card {
  border: 1pt solid Gray;
  .title {          /* .card .title と同じ */
    font-weight: bold;
  }
  > .body {         /* .card > .body と同じ */
    margin: 5pt;
  }
  &.wide {          /* .card.wide と同じ */
    width: 100%;
  }
}
```

`&`は外側のセレクタに置き換わります。`&`を書かなければ子孫
(空白で結合)になります。`> .x`のように結合子で始めることもできます。
外側がカンマ区切りの複数セレクタなら、その全通りに展開されます。

入れ子の後ろに宣言を書いた場合も、書いた順にカスケードされます。

<div class="note">

入れ子のセレクタの詳細度は、展開後のセレクタごとに決まります
(CSSの仕様は`:is()`で包んだ場合と同じ詳細度に揃えますが、
Sassなどのプリプロセッサと同じ扱いにしています)。

規則の中に入れ子にした`@media`などの条件規則には対応していません
(無視されます)。規則の外側にある`@media`の中の入れ子は使えます。

</div>

### <a id="style-css-variables">カスタムプロパティ(CSS変数)<span class="since">4.0.0</span></a>

`--`で始まる名前のプロパティを宣言しておき、`var()`関数で参照できます。
色や寸法を1箇所で決めておきたいときに使います。

```css
:root {
	--main-color: #1f3a5f;
	--gutter: 12mm;
}

h1 {
	color: var(--main-color);
	border-bottom: 3pt solid var(--main-color);
}

p {
	margin-left: var(--gutter);
}
```

カスタムプロパティは**継承します**。上の例のように`:root`(文書のルート要素)へ
まとめて宣言しておけば、文書全体から参照できます。

#### 値が無いときの既定値

2つめの引数に、そのカスタムプロパティが宣言されていなかった場合に使う値を
書けます。

```css
p {
	margin-left: var(--gutter, 10mm);
}
```

#### 入れ子

カスタムプロパティの値の中で別のカスタムプロパティを参照できます。

```css
:root {
	--base: 10pt;
	--large: var(--base);
}
```

<div class="note">

**循環参照は無視されます。** `--a: var(--b); --b: var(--a);`のように
互いを参照し合う宣言は、その宣言が無かったものとして扱われます
(エラーにはなりません)。連鎖が64段を超える場合も同様です。

`var()`は**トークンの置き換え**として働きます。置き換えた結果が
そのプロパティの正しい値になっていなければ、その宣言は無視されます。

</div>

### <a id="style-css-atrules">使用できる@規則<span class="since">4.0.0</span></a>

| @規則 | 対応 |
| --- | --- |
| `@import` | url()とmedia指定に対応します。入れ子は10段までです。 |
| `@media` | メディアタイプに加え、`width` `height` `min-width` `max-width` `min-height` `max-height` `orientation`の各特性と、`and` `not`、入れ子に対応します。特性の長さには絶対単位のほか`em`・`rem`が使えます(メディアクエリの仕様どおり、常に初期フォントサイズ16pxを基準に解決します)。 |
| `@supports` | `and` `or` `not`と括弧による入れ子に対応します。プロパティ名が使用でき、かつ値が解釈できる場合に真になります。 |
| `@layer` | ブロック形式`@layer 名前 { }`、匿名`@layer { }`、文形式`@layer a, b, c;`に対応します。入れ子はドットで結合した名前(`a.b`)の独立したレイヤーとして扱います。 |
| `@page` | `:first` `:left` `:right`、<a href="#style-named-pages" class="pageref">名前付きページ</a>(`@page 名前`)<span class="since">4.0.0</span>、16個のマージンボックス、および`size`プロパティ<span class="since">4.0.0</span>に対応します。<a href="#style-page-margin-boxes" class="pageref">ページのマージンボックス</a>を参照してください。 |
| `@font-face` | <a href="#style-webfont" class="pageref">WebFont</a>を参照してください。 |
| `@counter-style`<span class="since">4.0.0</span> | 箇条書きや番号の形式を自分で定義できます。<a href="#style-counter-style" class="pageref">独自の番号形式</a>を参照してください。 |
| `@keyframes` `@namespace` | 無視します。 |

<div class="note">

用紙サイズは<span class="ioprop">output.page-width</span>・
<span class="ioprop">output.page-height</span>入出力プロパティのほか、
`@page`の`size`プロパティ<span class="since">4.0.0</span>でも指定できます。
両方が指定された場合は`size`が優先されます。

`@media`の特性クエリは、入出力プロパティで確定した用紙サイズに対して
評価されます(`@page`の`size`による上書きは`@media`の判定には
反映されません)。

`@layer`は、`!important`宣言によるレイヤー優先順位の反転には対応していません
(通常の宣言では仕様どおりに動作します)。

</div>

### <a id="style-css-default-stylesheet">デフォルトのスタイルシート</a>

ドキュメント内の記述に関係なく、特定のスタイルシートを適用する機能があります。 <span

### <a id="style-css-length">長さの単位</a>

CSSでは、絶対単位としてmm, cm, in, pt, pcが使われます。 各絶対単位は、Copper
PDFはCSSの仕様どおり次の一定の長さでレイアウトします。 PDFではptが長さの単位の基準となり、Copper
PDFでも内部的な単位としてptを使用しています。 以下は各単位の関係です。

<dl>

<dt>mm</dt>
<dd>1mm = 1/25.4in ≒ 2.835pt</dd>
<dt>cm</dt>
<dd>1cm = 10mm ≒ 28.35pt</dd>
<dt>in</dt>
<dd>1in = 72pt = 25.4mm</dd>
<dt>pt</dt>
<dd>1pt = 1/72in ≒ 0.353mm</dd>
<dt>pc</dt>
<dd>1pc = 1/6in = 12pt ≒ 4.233mm</dd>

</dl>

相対単位としてem, ex, rem, ch, lh, pxがあり、これは状況によって変化します。

em, exはそれぞれフォントの高さとxの高さを基準とした単位です。
正確には、文書中の基準となる位置で利用可能なフォントの高さの最大値と、xの高さの最大値を基準とします。
xという文字が存在しないフォントでは、exはxの高さではない「適当な高さ」となります。
remは文書のルート要素のフォントの高さ、chはexと同様の近似による文字幅を基準とします。

lh<span class="since">4.0.0</span>はその要素の計算済みline-heightを基準とした単位です。
`line-height`プロパティ自身にlhを書いた場合は、CSSの仕様どおり継承値(親要素の行の高さ)を基準とします。
`transform`プロパティの中では、em・rem等と同様に初期フォントサイズを基準とした近似で解決します。

pxは、<span class="ioprop">output.resolution</span>で設定される解像度が基準となります。
デフォルトでは96dpiで、この状況では1pt ≒ 1.33pxとなり、1pxは1ptより若干小さくなります。
この値は、一般的なブラウザに合わせたものです。

ラスター画像として結果を出力する場合、デフォルトでは出力結果の1ピクセルは常にCSSの1pxに一致します。 詳細は<a class="pageref" href="#style-output-image-resolution">画像の出力</a>を参照してください。
