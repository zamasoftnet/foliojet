<h2 id="prog-limit">動作の制限</h2>

**不特定の利用者が入力した文書を変換する**場合、サーバーを守るための
設定が必要です。この章ではその機能をまとめて説明します。

守るべきものは2つあります。

<dl>

<dt>読ませてはいけないものを読ませない</dt>
<dd>文書に書かれた参照をたどって、サーバーが本来見せてはいけない
	ファイルや社内のURLを読みに行ってしまうのを防ぎます。
	→ [読み込むリソースの制限](#prog-input-restriction)</dd>
<dt>使わせすぎない</dt>
<dd>極端に大きい主文書、多数・大量の外部資源、ページ数の多い結果や
	大きな出力は、意図的かどうかに関わらずサーバーへ大きな負荷をかけます。
	→ [入力容量と外部資源の制限](#prog-input-size-limit)、
	[ページ数の制限](#prog-page-limit)、[データサイズの制限](#prog-size-limit)</dd>
<dt>止まらない処理を打ち切る</dt>
<dd>文書1件の経過時間は<span class="ioprop">processing.time-limit</span>で
	ミリ秒単位に制限できます。複数パスでは全パスを合わせた時間です。
	既定の0は無制限です。<br />
	開発時に、ページが1つも進まない状態だけを検出するには、
	JVMシステムプロパティ<tt>-Dfoliojet.noProgressSeconds=秒数</tt>を
	指定します。<b>既定は無制限(検出しない)です</b>——実運用文書には
	時間のかかる正当な変換があるためで、開発・テスト環境でのハングアップ
	検出用途を想定しています。<b>これは変換1件に対する制限</b>で、
	接続に対するタイムアウト(サーバー製品が別に持つもの)とは異なります。</dd>

</dl>

出力の制限が働いた場合、ドライバは例外を投げるか、
文書変換のための関数が戻り値としてエラーを返します。
その際、ドライバのエラーハンドラには(警告や致命的エラーではなく)エラーが通知されます。

### <a id="prog-input-restriction">読み込むリソースの制限</a>

文書には、スタイルシートや画像など**外部のリソースへの参照**が書けます。
組版エンジンはこれを読みに行きます。

利用者が投稿したHTMLを変換するような使い方では、これは危険です。
`file:///etc/passwd`や、社内ネットワークだけから見えるURLを書かれると、
**サーバーに代わりに読みに行かせる**ことができてしまうためです。

そこで**既定では外部のリソースを一切読みません**。

<div class="note">

**画像やスタイルシートが反映されない場合は、まずここを疑ってください。**
許可を設定していないと、参照は読み込まれずに無視されます。

</div>

#### 許可と禁止の設定

<span class="ioprop">input.include</span>に許可するURIのパターンを、
<span class="ioprop">input.exclude</span>に禁止するURIのパターンを設定します。
どちらも**何度でも設定でき**、**設定した順に評価されます**。

パターンで使えるワイルドカードは2種類です。

| 記法 | 意味 |
| --- | --- |
| `*` | `/`を含まない任意の文字列 |
| `**` | `/`を含む任意の文字列 |

判定は次のように行われます。

1. 設定した順にパターンと照合し、**最初に一致したものが結果を決めます**
	(includeに一致すれば許可、excludeに一致すれば禁止)
2. どのパターンにも一致しなければ**禁止**します

```java
// 自社サイト以下だけを許可する
session.property("input.include", "https://www.example.com/**");

// ただし管理画面は除く(includeより先に評価させるため先に設定する)
session.property("input.exclude", "https://www.example.com/admin/**");
session.property("input.include", "https://www.example.com/**");
```

**順序が結果を変えます。** 上の例で`input.include`を先に設定すると、
`/admin/`もincludeに先に一致してしまい、禁止は効きません。

すべて許可する場合は次のようにします。
信頼できる文書しか処理しない場合に限ってください。

```java
session.property("input.include", "**");
```

#### data: URIは常に読み込まれます

`data:`で始まるURI(内容をURIの中に直接埋め込んだもの)は、
設定に関わらず常に読み込まれます。
リソースの内容をURI自身が持っているため、
サーバーに何かを読みに行かせる手段にはならないからです。

#### 迂回できないようにしている点

URIは**正規化してから**照合します。
また、http/httpsのURIでは`%xx`の形式のエスケープを解いてから照合します。
`%2e%2e/`のような書き方で`../`を隠したり、
同じリソースを別の書き方で指したりして、パターンをすり抜けることはできません。

#### アプリケーションから直接渡す方法

そもそもサーバーに読みに行かせず、**アプリケーションが内容を渡す**方法もあります。
この場合もURIの許可・禁止と、下記の資源数・容量制限は適用されます。
**APIによるアクセスの概要**(サーバー製品の説明書)のソースリゾルバを参照してください。

### <a id="prog-input-size-limit">入力容量と外部資源の制限</a>

不特定の利用者から文書を受けるサービスでは、URIの許可範囲だけでなく、
読み込む量にも上限を設定してください。

| プロパティ | 単位 | 制限するもの |
| --- | --- | --- |
| <span class="ioprop">input.size-limit</span> | バイト | 主文書1件。EPUBではEPUBファイル全体 |
| <span class="ioprop">input.resource-size-limit</span> | バイト | 主文書から解決した外部資源の累積読込量 |
| <span class="ioprop">input.resource-count-limit</span> | URI数 | 主文書から解決した相異なる外部資源 |
| <span class="ioprop">processing.time-limit</span> | ミリ秒 | 文書1件の変換全体。複数パスは合算 |

いずれも既定では無制限です。容量制限を使う場合、入力はバイト列を返す
`Source`として渡してください。文字`Reader`だけを返す独自`Source`では、
文字数と符号化後のバイト数が一致しないため安全側に失敗します。

外部資源の数は同じ正規化URIを複数回参照しても1件です。累積容量は実際に
読み込んだバイトを数えるため、同じ資源を再取得すればその分も加算されます。
`data:` URIも入力内容なので容量制限の対象です。

```java
session.property("input.size-limit", "10485760");           // 主文書10MiB
session.property("input.resource-size-limit", "52428800"); // 外部資源合計50MiB
session.property("input.resource-count-limit", "200");
session.property("processing.time-limit", "30000");        // 30秒
```

### <a id="prog-page-limit">ページ数の制限</a>

出力結果が一定のページ数に達した場合に、強制的に処理を中断する機能です。

<span class="ioprop">output.page-limit</span>に、出力する最大ページ数を設定してください。
デフォルトでは、ページ数の制限はありません。

ページ数の制限を越えた場合、途中までのページを結果として出力するか、結果を破棄するかどうかを選ぶことができます。

<span class="ioprop">output.page-limit.abort</span>に、"normal"を設定すると、途中までのページを結果として出力します。
"force"を設定すると、結果を破棄します。デフォルトは"force"です。

ただし、[2パス以上の処理](#style-multipass)を行う場合は、最終パス以外でページ数が限界に達すると結果が破棄されます。
また、（PDFではなく）画像として結果を出力する場合は、（最終パスの場合）いずれの場合も途中までページが出力されます。

### <a id="prog-size-limit">データサイズの制限</a>

出力結果が一定の物理的なサイズに達した場合に、強制的に処理を中断する機能です。

<span class="ioprop">output.size-limit</span>に、最大データサイズをバイト単位で設定してください。
デフォルトではデータサイズの制限はありません。
