## Document layout

Because it uses HTML, CSS, and other standard methods for creating web content,
you can create PDFs in much the same way if you know how to create web content. This document explains Copper
PDF-specific features and points to keep in mind.

### How to lay out a document

Laying out a document is much like creating a typical web application.
Use an HTML editor or similar tool to create HTML or a template for a program to process,
then convert it to PDF programmatically.

A tool called <b>copper-webapp</b> (server product manual) lets you check the output easily.
Start this tool to convert HTML files on your local machine to PDF through a web-based interface.
