## I/O properties

To configure product-specific features and settings equivalent to the preferences and options in a typical browser,
set "I/O properties," which are name and value pairs. For a list, see <a class="pageref" href="#appx-ioprops">I/O properties in the reference section</a>.

I/O properties can be set by a programmer
through <b>Programmatic configuration</b> (server product manual), or by a system administrator
through the <b>Default I/O property configuration file</b> (server product manual).

You can also set I/O properties in HTML or XML documents with the [jp.cssj.property](#appx-pi-jp.cssj.property) processing instruction.
However, you must first set <span class="ioprop">input.property-pi</span>
to true in the program or configuration file. Specify the property name in the processing instruction's name attribute and its value in the value attribute, as shown below.
Always place the instruction between the beginning of the document and the first element.

```xml
<!DOCTYPE HTML PUBLIC "-//W3C//DTD HTML 4.01//EN">
<?jp.cssj.property name="output.pdf.encryption" value="v2"?>
<?jp.cssj.property name="output.pdf.encryption.user-password" value="user"?>
<?jp.cssj.property name="output.pdf.encryption.owner-password" value="owner"?>
<?jp.cssj.property name="output.pdf.encryption.permissions.print" value="false"?>
<!--
To enable the settings above, input.property-pi must be set to true in the program or configuration file.
-->
<html>
  <head>
    <meta http-equiv="Content-Type" content="text/html; charset=UTF-8">
    <title>Encryption 1</title>
    <style type="text/css">
    </style>
  </head>

  <body>
    <h1>Encryption 1</h1>
    <p>
      The user password for this document is "user" and the owner password is "owner".
      Printing is prohibited.
    </p>
  </body>
</html>
```

Some properties cannot be set with the jp.cssj.property processing instruction. For details, see the <a class="pageref" href="#appx-ioprops-nopi">reference section</a>.
