## <a id="appx-css">CSS property support</a>

The following table shows support for each property in W3C CSS 2.1, which forms the basis of the implementation.
It does not limit the overall conformance level to CSS 2.1.
For modules from CSS3 and later (multi-column layout, vertical writing, Grid layout, logical properties,
Japanese typesetting extensions, and others), see the lists of
<a href="#appx-css3">Modules from CSS3 and later</a> at the end of this page and
<a href="#appx-cssprop-ext">CSS extensions</a>.
